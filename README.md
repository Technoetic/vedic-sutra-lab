# SUTRA / LAB

베다 수학의 16가지 수트라를 **순서 없이 자유롭게 탐색하는 한국어 튜토리얼**입니다. 숫자를 바꾸면 풀이·도식·결과가 함께 바뀝니다.

**튜토리얼:** https://technoetic.github.io/vedic-sutra-lab/

- 16개 규칙과 기초·응용·심화 필터, 검색
- 예제마다 1~3개의 실제 숫자 조작, 풀이 단계 펼치기
- 적용 조건과 잘못된 입력 안내, 원전·교육 해설 링크
- 이 브라우저에 예제 저장, 미저장 입력과 진행 중 저장 보호
- 기존 블로그 이미지 카드16장 보기, 키보드·모바일 지원
- 서버 계정·분석 추적·외부 API·패키지 설치 없이 동작

## 실행

Node.js 24에서 검증했습니다. 별도 `npm install`은 필요 없습니다.

```sh
npm test
npm run build
npm start
```

기본 주소는 `http://127.0.0.1:8796/`입니다. 다른 포트는 `PORT` 환경변수로 지정합니다. 전달 ZIP에는 바로 실행할 `dist/`도 포함합니다. 로컬 파일을 더블클릭하는 대신 HTTP 서버로 열어 주세요.

직접 링크 예: `https://technoetic.github.io/vedic-sutra-lab/#/sutra/13`. 상대 자산과 hash 화면 URL을 사용하므로 GitHub Pages의 하위 경로에서도 동작합니다.

## GitHub Pages 배포

`main` 갱신 시 GitHub Actions가 계산·앱 시험을 통과한 뒤 완성된 `dist/`를 Pages에 배포합니다. 이전 공개본의 `asset-manifest.json`에 있는 해시 자산을 검증해 유지합니다. 최초 공개에서 대장이404인 경우만 건너뛰며, 다른 조회·무결성 실패는 배포를 중단합니다. Actions는 고정된 커밋을 사용합니다.

## 내용의 범위

1965년 출간된 바라티 크리슈나 티르타의 체계와 원전 색인을 참고한 현대적 교육 자료입니다. 고대 경전 기원을 확정해 표현하지 않습니다. 9·16번은 순간 변화율, 13번은 특정 분수 방정식입니다. 11번은 원전의 대칭적인 사차식 묶기를 제곱식으로 단순화한 교육용 확장입니다. 15번의 계수 합 검산은 식 전체의 일치를 증명하지 않습니다.

16개 이미지 카드는 선행 작업의 내장 image_gen 원본을 내용 변경 없이 WebP로 변환했습니다. 첫 화면에는 로드하지 않으며 카드 보기를 요청할 때 가져옵니다.

## 웹앱 6원칙

소스는 화면·서비스·수학·도식·공통 모듈, CSS는 토큰·기본·컴포넌트로 나뉩니다. 학습 자료는 비동기 로드와 재시도·취소를 지원합니다. 새 배포의 식별자가 다르면 다음 안전한 이동에서 전체 문서를 받으며, 편집·저장 중에는 현재 값을 보존합니다. 배포된 자산은 내용 해시를 사용하고 빌드는 기존 해시 자산을 지우지 않습니다.

현재 브라우저에 저장한 예제는 다른 기기와 동기화하지 않습니다. 브라우저 데이터를 지우면 없어집니다.

## 검증

`docs/verification/`에 실제 결과와 미검증 범위를 남겼습니다.

- Node 시험107/107(계산·저장·이동·캐시·이전 자산 보존), 독립 수학·도식 입력38,922조합
- 실제 Aside 브라우저: 16규칙 입력·풀이·저장·재열기와 이미지 카드 디코드
- 홈+16규칙 ×320/390/768/1440: 68화면, 가로 넘침0
- 로컬 A→B 전체 문서 이동·롤백·dirty 보호·저장 중/확인 중 편집·실패 복구
- 직접 링크·새로고침·Back/Forward·진짜404·캐시 헤더

선행 로컬 검증에서는 외부 호스팅/CDN과 네이티브 BFCache 복원을 검사하지 않았습니다. 공개 후 검증은 별도 공개 기록으로 구분합니다. Aside의 화면 캡처는 CDP 시간 초과로 확보하지 못했으며, 실제 DOM 조작·레이아웃·계산 검증과 구분합니다.
